# Inkfist

Пригода майстра бойових мистецтв у стилі живопису тушшю. Натхненна класичними
бічними іграми про карате 1980-х, але з власним сюжетом, героями й сучасною графікою.
Python + pygame-ce, уся графіка й музика генеруються в коді.

Триста років Вітряний дзвін лунав над долиною. Минулої ночі Володар Семи Вітрів
викрав його і втік на вершину. Учитель надто старий для підйому — тож іти тобі.

- **6 розділів**: бамбуковий гай, річкова ущелина, монастир дощу, сніговий перевал,
  вогняний храм і штормова вершина — кожен зі своєю погодою та музикою
- **5 типів ворогів** (розбійник, здоровань, списник, тінь, монах) і **6 босів**
  зі своїм стилем бою; фінальний бос має дві фази
- **Нові прийоми після кожного розділу**: підсічка, ухилення, ідеальне парирування,
  удар у стрибку, долоня духу
- Стріли й каменепади між боями, контрольні точки на кожен розділ, «дух» для повторних спроб
- Клавіатура й геймпад, три рівні складності
- Мови: English, Українська, Polski, Deutsch, Français, Español

## Керування

| Дія | Клавіатура | Геймпад |
|---|---|---|
| Рух | ← → / A D | лівий стік / хрестовина |
| Присід | ↓ / S | ↓ |
| Удар рукою | J / Z | X |
| Удар ногою (↑ + нога — високий) | K / X | A |
| Блок (присід + блок — нижній) | L / C / Shift | LB |
| Підсічка | ↓ + K | ↓ + A |
| Ухилення | Пробіл | B |
| Удар у стрибку | U / V | Y |
| Долоня духу | I / B | RB |
| Пауза | P / Esc | Start |

## Запуск із вихідного коду

```bash
sudo apt install python3-venv gettext
./tools/compile_translations.sh
python3 -m venv .venv && . .venv/bin/activate
pip install -e .
inkfist --windowed
```

## Структура

```
src/inkfist/skeleton.py   скелет бійця: пози, кінематика, малювання силуетів
src/inkfist/fighter.py    прийоми, удари/блоки/парирування, ШІ ворогів і босів
src/inkfist/world.py      розділи, пейзажі з паралаксом, погода
src/inkfist/sound.py      синтез звуків і музики (лад хірадзьоші, барабани тайко)
src/inkfist/game.py       перебіг гри, меню, HUD, сюжет
```
